The Total Visitors counter is a shared online counter and is displayed directly on the website.
It counts page hits; refreshing/reopening can create additional hits.

Supabase visitor analytics setup:
1. Open Supabase SQL Editor.
2. Run supabase-setup.sql once.
3. Deploy this site.
4. Open /admin.html and use the existing admin password.
The admin panel shows Human Visitor/Bot Visitor, approximate city/country and date/time. IP addresses are not stored.
